## Case Study: ATM Application

This program simulates an ATM application
that allows customers to perform three transactions.

### Features
1. Balance Inquiry - Displays the current account balance.
2. Cash Withdrawal - Deducts the withdrawal amount if sufficient balance is available.
3. Cash Deposit - Adds the deposit amount to the current balance.

The program also displays an appropriate message
for an invalid option.

## Programming Language
C

## File
- atm_application.c - Implements the ATM transactions using a switch statement.
